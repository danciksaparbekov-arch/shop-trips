# Сходим в магазин?

Общий список покупок для коллег. Один идёт в магазин и создаёт поход, остальные по ссылке дописывают, что им нужно. Потом покупатель вносит цены, прикладывает чек и QR для оплаты, а сайт считает, кто сколько должен.

- Вход без регистрации: только имя (анонимный вход Supabase, у каждого браузера свой скрытый id).
- Поход открывается только по секретной ссылке-приглашению; общего списка походов нет.
- Цены позиций можно запомнить: в следующем походе они подставятся сами, а тем, кто пишет список, показывается ориентир «≈ цена».
- Чеки и QR лежат в закрытом хранилище и показываются участникам по временным ссылкам.

## Стек
Vite + React, Supabase (Postgres + RLS, Auth, Storage), GitHub Pages.

## Настройка
1. Создать проект Supabase, в SQL Editor выполнить `supabase/schema.sql`.
2. Authentication → Sign In / Providers → включить **Allow anonymous sign-ins**.
3. Скопировать `.env.example` в `.env.local` и вписать `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` (publishable-ключ).
4. `npm install`, затем `npm run dev`.
5. Деплой: секреты репозитория `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`, Pages → Source: GitHub Actions.
